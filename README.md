# Custom Song Web 🎵

A web platform where users can order **personalized songs** created specifically for them.
Each song is tailored based on the user's story, emotions, and preferences.

## 🚀 Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## 📦 Getting Started

Install dependencies:

````bash
npm install
````
